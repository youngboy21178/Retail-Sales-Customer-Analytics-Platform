# ТЗ: Retail Sales & Customer Analytics Platform

**Мета проєкту:** закрити три конкретні прогалини, які вже спливали в реальних вакансіях —
SQL-впевненість під тиском (Lenovo), Excel Power Query/VBA (Covestro), і BI-дашборд
(немає в портфоліо взагалі). Один проєкт, який покриває всі три.

**Орієнтовний час:** 15–25 годин загалом, можна розтягнути на 2-3 вихідних.

**Результат:** GitHub-репозиторій + Power BI дашборд (скріншоти/файл) + короткий README
з бізнес-інсайтами — те, що можна прямо кидати в наступних cover letters.

---

## Датасет

Використай **Kaggle "Online Retail II" dataset** (UK e-commerce, реальні транзакції, ~1 млн рядків)
або **Olist Brazilian E-commerce dataset** (більший, з таблицями customers/orders/products/reviews —
краще імітує реальну реляційну структуру, яку побачиш на роботі).

Рекомендую **Olist** — багато таблиць, треба буде робити JOIN-и, це ближче до реального job market.

Посилання: `kaggle.com/datasets/olistbr/brazilian-ecommerce`

## Фаза 1 — SQL (закриває прогалину Lenovo: синтаксис під тиском)

**Інструмент:** PostgreSQL (в тебе вже встановлений з попередніх проєктів) + pgAdmin або DBeaver для зручного перегляду.

**Завдання:**
1. Імпортуй усі CSV-таблиці Olist у PostgreSQL (`\copy` або через pgAdmin import).
2. Напиши SQL-схему з правильними **primary/foreign keys** між таблицями (orders, customers, order_items, products, reviews).
3. Виконай і задокументуй (збережи `.sql` файл із коментарями) щонайменше **12 аналітичних запитів**, які покривають:
   - `JOIN` між 3+ таблицями
   - `GROUP BY` + агрегатні функції (SUM, AVG, COUNT)
   - `Window functions` (`RANK()`, `ROW_NUMBER()`, `LAG()/LEAD()`) — це саме те, де найчастіше "плаваєш" на співбесіді
   - `CTE` (`WITH ... AS`) для багатоступеневих запитів
   - `CASE WHEN` для сегментації (наприклад, категорії клієнтів за сумою покупок)
   - Підзапити (subqueries) в `WHERE`/`SELECT`

**Приклади конкретних бізнес-питань, які запити мають відповісти:**
- Топ-10 категорій товарів за виручкою по місяцях.
- Які клієнти зробили повторні покупки (retention) і скільки часу між покупками (LAG/LEAD).
- RFM-сегментація клієнтів (Recency, Frequency, Monetary) — класична задача data analyst.
- Кореляція між часом доставки і рейтингом відгуку (review score).

**Практика синтаксису під тиском:** після написання своїх запитів — прогони **10-15 задач на DataLemur**
(SQL-специфічно для data analyst, а не LeetCode-алгоритми) без підглядання в довідник, з таймером 5-7 хв на задачу.

## Фаза 2 — Excel: Power Query + VBA (закриває прогалину Covestro)

**Завдання:**
1. Експортуй результат одного зі своїх SQL-запитів (наприклад, місячна виручка по категоріях) у CSV.
2. У Excel — підключи цей CSV через **Power Query** (Data → Get Data → From Text/CSV), а не просто відкрий файл. Зроби в Power Query:
   - Трансформацію типів даних
   - Pivot/Unpivot колонок
   - Merge Queries (об'єднання двох джерел — наприклад, продажі + довідник категорій)
3. Побудуй **VBA-макрос**, який автоматизує щось конкретне, наприклад:
   - Кнопка "Refresh Report" — оновлює всі Power Query-з'єднання і зберігає копію файлу з датою в назві.
   - Автоматичне форматування нового аркуша (кольори, межі, автопідбір ширини колонок) після оновлення даних.
4. Збережи файл `.xlsm` (з макросами) і додай короткий `.gif`/скріншот роботи макросу в README.

**Мінімальний обсяг:** 1 Power Query трансформація + 1 робочий VBA-макрос — цього достатньо, щоб чесно написати "Excel (Power Query, VBA)" в резюме.

## Фаза 3 — Power BI дашборд (портфоліо-центральний елемент)

**Інструмент:** Power BI Desktop (безкоштовний, встанови з офіційного сайту Microsoft).

**Завдання:**
1. Підключи Power BI напряму до твоєї PostgreSQL бази (Power BI має нативний PostgreSQL-конектор).
2. Побудуй дашборд з мінімум **4 візуалізаціями**:
   - Line chart: виручка по місяцях (тренд)
   - Bar chart: топ категорій/продуктів
   - Map: продажі по регіонах Бразилії (Olist має географічні дані)
   - KPI-картки: загальна виручка, середній чек, кількість замовлень
3. Додай **2-3 DAX-міри** (не просто drag-and-drop готові поля) — наприклад:
   - `YoY Growth %` (рік до року)
   - `Average Order Value`
   - `Customer Retention Rate`
4. Додай **фільтри/slicers** (по даті, категорії, регіону) — щоб дашборд був інтерактивним, а не статичним.
